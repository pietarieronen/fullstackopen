# 0

## [0.1 - HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content)

- HTML is a markup language (text encoding system) that is used to structure a web page and its content. Html files are documents that contain elements. The top level elements are html (root wrapper), head (links and others that are not directly content) and body (the content to display)

## [0.2 - CSS](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content)

- CSS is a style sheet language and it is used to style html elements. CSS works combining the use of selectors, declarations, properties and property values. One structured piece of css is called ruleset.

## [0.3 - HTML Forms](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Your_first_form)

- Forms are the main point of interaction between the user and the website. Forms are a contained set of controls (or widgets) and optional validations.
